- [ ] 테스트는 리팩토링 경계를 직접 확인합니다.

## 3. 실패 케이스 확인

- [ ] 존재하지 않는 사용자를 조회할 때 의도한 예외로 이어지는지 확인합니다.
- [ ] 리팩토링 후 기존 성공 시나리오가 유지되는지 확인합니다.
