# 리팩토링과 기초 보강 제공 자산

## 미리 제공하는 것

- 10 시퀀스 answer 기반 프로젝트
- 기존 서비스 코드
- 기존 테스트 구조
- 문서 기본 틀
- 현재 예외 응답 구조

## 왜 미리 제공하는가

- 이번 시퀀스의 핵심은 새 기능 구현이 아니라 구조를 다시 읽고 정리하는 것입니다.
- 학생이 보일러플레이트보다 리팩토링 포인트에 집중하게 만들기 위함입니다.
- 전/후 비교가 잘 보여야 하기 때문에 시작 기준 코드를 그대로 제공합니다.

## 학생이 직접 작성하지 않는 범위

- 새로운 대형 기술 주제
- 대규모 패키지 재구성
- 멀티모듈 분리
- 고급 성능 최적화
- 이벤트 기반 구조 전체
